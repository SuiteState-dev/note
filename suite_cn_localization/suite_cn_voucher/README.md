# China - Accounting Voucher (记账凭证 / M3a)

中式记账凭证呈现层。在上游 `l10n_cn` 的记账凭证打印报表上补齐中式法定要素，**纯呈现层**，
不新增第二条记账路径、不做审核签章工作流。

## 做什么

- **凭证字**（`l10n_cn_voucher_word`，Selection：收款/付款/转账/记，默认「记」）。
- **凭证号**（`l10n_cn_voucher_number`，Integer，按 公司 × 凭证字 × 会计期间 连续编号）。
  - 过账时分配；显示为「记-1」（前缀是呈现层格式，不入存储）。
  - 取号走 `ir.sequence` + `use_date_range`，每（公司 × 凭证字）一条序列，**按月归零**
    （自建月度 `date_range`——Odoo 自动建的是年粒度）。
- 打印版式：**中文化** + 一级—明细科目串（点分编码截首点取一级，取不到原样打全名）
  + 借贷合计 + 金额大写（`cn2an`）+ 附件张数 + 签章栏位。

## 设计边界（重要）

- **完全不碰 `account.move.name`**。`account.move` 走 `sequence.mixin`、不走 `ir.sequence`
  （B-52），两套机制独立；卸载删两列，原生编号不受影响（P-01）。
- **过账才给号**：草稿态的 move（每张草稿发票都是）不占号。金蝶「保存即给号」对应的是
  Odoo 的**已过账**，不是草稿——草稿给号会把号被草稿吃光。
- **凭证号删除会释放号（接受断号）**：运营口径是**不删已过账凭证、走红冲**（红冲自带一张
  新的连号凭证，连续性完整）。断号检查（按 公司×期间×凭证字 列断号区间）另行提供，不在本模块。
- **签章只留栏位，不做工作流**：审核/签章属流程层（M3b），(b) 法定但等客户信号。
- **借方红字**：Odoo `debit`/`credit` 非负，「借方红字」被存成「贷方蓝字」是框架层限制，
  呈现层无法凭空还原 → 仅作显示注意项，不声称已解决。
- **附件 0 张是合规的**（结账/更正错误的凭证可不附原始凭证），不当异常告警。
- **分数编号**（一笔业务多张凭证）首版不支持——法规**允许**分数编号，本模块只是暂未实现，
  不代表法规禁止。

## 依赖 / 卸载

- 依赖 `l10n_cn`（复用其凭证报表骨架 + `account.move` 的金额大写/附件计数）。
- `uninstall_hook` 清理懒创建的凭证号序列；两个字段列随模块卸载自动删除。
